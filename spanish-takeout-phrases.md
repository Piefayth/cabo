# Spanish Takeout Phrases

## Asking for a To-Go Box

| Spanish | English |
|---|---|
| ¿Me puede dar una caja para llevar, por favor? | Can you give me a to-go box, please? |
| ¿Podría traerme una caja para llevar? | Could you bring me a to-go box? |
| Quisiera una caja para llevar. | I'd like a to-go box. |
| ¿Tiene cajas para llevar? | Do you have to-go boxes? |

## Other Useful Takeout Phrases

| Spanish | English |
|---|---|
| ¿Puedo pedir para llevar? | Can I order takeout? |
| Quiero esto para llevar. | I want this to go. |
| ¿Me lo puede empacar? | Can you pack it up for me? |
| La cuenta, por favor. | The check, please. |

## Key Vocabulary

- **para llevar** - to go / takeout
- **caja** - box
- **bolsa** - bag
- **empacar** - to pack up
- **la cuenta** - the check/bill
